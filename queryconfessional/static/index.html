How to read this inventory

Counts measure query records, including repeats. A query can be served from the resolver's cache. Devices using encrypted DNS or another resolver will be missing. An empty result means no matching imported records, not no network activity.

Reimporting an unchanged or appended file at the same path is safe. A copied, renamed or rotated file is a new source and will count those records again. Import each capture under one stable path; do not import overlapping rotations.

System logs without a year or timezone use the values supplied during import. Split logs spanning New Year into separate files. Times in the tables use your browser timezone; CSV exports use UTC.

Nothing is uploaded. There are no domain reputation lookups, geolocation calls, third-party scripts or analytics. Exported files contain private browsing metadata: store them accordingly.
